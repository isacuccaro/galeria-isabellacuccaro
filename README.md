# Galería de Flores
Este sitio web presenta una galería de flores.

## Elementos de la galería
- Rosas
- Flores blancas

## Páginas

- index.html
- rosas.html
- blancas.html

## Decisiones de diseño

Para el sitio elegí una paleta de colores suaves, utilizando tonos verdes,
rosas y crema, porque se relacionan con la naturaleza y las flores de la galería.

Para los textos utilicé Arial, ya que es una tipografía simple y fácil de leer.
Para los títulos utilicé Georgia para diferenciarlos del resto del contenido.

La intención fue mantener un diseño simple, claro y relacionado con la temática floral.
